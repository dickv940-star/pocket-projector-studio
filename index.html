Pocket Projector Studio

Gunakan layar Android sebagai sumber visual fullscreen untuk sistem lensa eksternal. Pilih video atau gambar, atur orientasi, lalu uji fokus dengan pola grid.

Lihat Source Code Build APK di GitHub Actions

Fitur MVP

  • Pemutar video dan penampil gambar lokal
  • Mode fullscreen dan pengaturan kecerahan
  • Koreksi flip horizontal / vertikal
  • Pola uji lensa dan fokus

Kompatibilitas build: Android 6.0 (API 23) ke atas. Proyeksi nyata tetap membutuhkan perangkat optik eksternal.
